# ArchXv2

Gallery of architectural images organized by categories.

## Image Gallery

View all images in an interactive gallery by opening `image-gallery.html` in your web browser.

### Categories

- **🏡 Biệt thự (Villa)** - 4 images
- **🏗️ Công Trình (Construction)** - 6 images  
- **🏘️ Nhà Phố (Townhouse)** - 7 images

### Features

- Interactive image gallery with hover effects
- Copy embed links for each image
- Responsive design for mobile and desktop
- Organized by architectural categories

### Usage

1. Open `image-gallery.html` in your web browser
2. Browse images by category
3. Click "View Image" to open full-size image
4. Click "Copy Link" to copy the image URL to clipboard
